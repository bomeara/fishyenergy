# Daily water temperature for many streams

This dataset contains modeled maximum daily water temperature for every
day of the year 2022 for all interconfluence reaches of the Little
River, TN.

## Usage

``` r
temps_casc
```

## Format

A data frame with 365 rows and 515 columns:

- date:

  (date) dates from 1 January 2022 to 31 December 2022

- COMID:

  (numeric) mean daily water temperature in degrees C for all 513 COMIDs

## Source

Southeastern Climate Adaptation Science Center (CASC).
